# Patel Times Watch Store

Patel Times Watch Store is a modern and responsive luxury watch shopping website developed using HTML, CSS, and JavaScript as part of the IT Workshop (2ES1111) Mini Project.

## Purpose of Website
The main purpose of this website is to provide users with an attractive online platform to explore premium and stylish watches with a smooth shopping experience.

## Technologies Used
- HTML
- CSS
- JavaScript

## Main Features
- Modern responsive design
- Watch product showcase
- Navigation menu
- Login and Register pages
- Shopping cart section
- Interactive user interface
- Smooth website layout

## Website Flow
Users can browse luxury watches, navigate through different sections, explore products, and interact with the website using various frontend features.

## Conclusion
This project helped in understanding frontend web development concepts, responsive design, website structure, and interactive UI development using HTML, CSS, and JavaScript.
